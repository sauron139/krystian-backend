# krystian-backend

FastAPI service that powers the platform: content API for the public site, authenticated
admin API, contact-form handling, media uploads, and background jobs.
System context: `../CLAUDE.md` and `../docs/` (especially `ARCHITECTURE.md` and `API.md`).

## Stack
Python 3.13 · uv · FastAPI · Pydantic v2 · SQLAlchemy 2.0 async + asyncpg · Alembic ·
PostgreSQL · Redis · BackgroundTasks (email) · S3 (R2 in prod; local stand-in TBD) · Ruff · mypy · pytest

## Structure
```
app/
├── main.py              # app factory, middleware, router registration
├── cli.py               # python -m app.cli seed | create-admin | ensure-dev-admin | export-openapi
├── seed.py              # placeholder content (is_placeholder=True), idempotent
├── core/                # config, errors (uniform shape), security (argon2, JWT), cache, rate_limit, email, redis
├── db/                  # Base + mixins (base.py), engine/session (session.py)
├── models/              # SQLAlchemy models: content.py, auth.py, inbox.py, media.py, enums.py
├── schemas/             # Pydantic: XIn (create) / XPatch (partial) / XOut per resource
├── services/            # business logic: content.py (generic CRUD + Resource registry), auth, contact, site
└── api/
    ├── deps.py          # SessionDep, AdminDep, ClientIP, PageDep
    └── v1/
        ├── public/      # health, read-only content (cached), POST /contact
        └── admin/       # auth, profile/settings/messages/checklist, generic CRUD routers
migrations/              # Alembic (async); versions/ is autogenerated, review before committing
scripts/dev-start.sh     # dev container: migrate → seed → dev admin → hot-reload server
tests/                   # real Postgres (krystian_test) + Redis DB 15
```
Adding a content type: model in `models/content.py` → schemas in `schemas/content.py` →
a `Resource(...)` in `services/content.py` (add to RESOURCES) → public route if needed →
`alembic revision --autogenerate`.

## Rules
- Routers are thin: validate input, call a service, return a schema.
- Every admin write calls `invalidate_public_cache()` (done in the service layer).
- Editing placeholder content clears `is_placeholder` automatically.
- Every schema change ships with an Alembic migration.
- Public endpoints never return drafts.
- Update `../docs/API.md` when the contract changes.

## Commands
Inside Docker (from `../krystian-infra`): `make test-backend`, `make migrate`,
`make migration m="..."`, `make seed`, `make openapi`, `make sh-backend`.
On the host (needs the stack's Postgres/Redis on localhost):
- `uv run pytest` · `uv run ruff check . && uv run ruff format .` · `uv run mypy app`
- `DATABASE_URL=postgresql+asyncpg://krystian:krystian-dev-only@localhost:5432/krystian uv run alembic upgrade head`
